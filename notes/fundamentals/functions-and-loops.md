# Functions and Loops

- **In my own words:** A function is a reusable block of code. The function definition tells Python what the function does, and the function call tells Python to run it when needed. A loop repeats a block of code so I do not have to write the same lines again and again. It keeps going through items in a list or until a condition is met.
- **Why it matters:** Functions reduce repeated code and make programs easier to read and maintain. Loops help process many values efficiently and are useful in real programs for lists, calculations, and repeated tasks.
- **Time / space complexity (if applicable):** For a simple loop over a list of length n, the time complexity is O(n).
- **Source:** Python fundamentals practice / CS50-style learning
- **Self-quiz result:** I can explain the difference between a function definition, a function call, and a loop, and I understand that loops repeat work while functions package reusable logic.
