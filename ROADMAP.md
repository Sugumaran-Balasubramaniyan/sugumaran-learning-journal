# Learning Roadmap

## How to use this roadmap
Work through one phase at a time. Keep the README's "This Week's Focus" section as the single source of truth for what to do right now; the roadmap is the long-range plan.

## Learning loop
For each new topic, use this sequence:
1. Explain the idea in plain language.
2. Walk through a tiny runnable example and a short code fragment, with an explanation of each part.
3. Try a small exercise independently; if stuck, use one focused hint plus an example on a different problem.
4. Check learning by explaining the idea, writing it yourself, and applying it to a new problem.
5. Record which activity helped, what remains confusing, and what to adjust next time in `log/learning-reflections.md`.

Use the three learning checks as evidence, not as a demand to get everything right on the first attempt. Revisit a topic when an explanation, independent implementation, or transfer problem still needs support.

## Phase 0 (Week 0)
**Focus:** Pick one language (Python is recommended for this goal) and complete environment setup.

**Resources:**
- Language basics for the chosen stack
- VS Code setup and terminal workflow
- Python or alternative runtime installation

**Milestone:**
- Working editor
- Able to run a hello-world from the terminal

## Phase 1 (Weeks 1–8)
**Focus:** Programming fundamentals.

**Resources:**
- CS50 on edX
- Automate the Boring Stuff

**Milestones:**
- Number-guessing game
- To-do CLI
- Web scraper

**Rule:** All of these should be written from scratch without AI help.

## Phase 2 (Weeks 9–24)
**Focus:** Core computer science.

**Subjects (four only):**
- Algorithms & Data Structures (Skiena / The Algorithm Design Manual)
- Computer Architecture (Berkeley CS 61C / Patterson & Hennessy)
- Operating Systems (OSTEP, free PDF)
- Databases (Berkeley CS 186 / Readings in Database Systems)

**Milestones:**
- Implement hash map from scratch
- Implement linked list from scratch
- Implement BST from scratch
- Write a one-page explanation of virtual memory

**Current sequence:** Binary search trees next. Linked list fundamentals and a hash map with insertion, retrieval, and collision handling have already been practiced in the sandbox.

## Phase 3 (Weeks 25–40)
**Focus:** DSA for interviews.

**Resources:**
- Blind 75
- NeetCode 150
- Targeted hard problems after the core set

**Method:** Timebox every problem to 35 minutes.

**Milestone:**
- 150–200 mediums solved in under 30 minutes
- Roughly 30 hards

## Phase 4 (Weeks 35–45, overlapping with Phase 3)
**Focus:** System design.

**Resources:**
- System Design Primer
- Grokking

**Milestone:**
- Five written-up designs:
  - URL shortener
  - Rate limiter
  - Notifications
  - Feed
  - Chat

## Phase 5 (Weeks 40+, ongoing)
**Focus:** Mock interviews and behavioral prep.

**Requirements:**
- Minimum two mock interviews per month from Phase 3 onward
- Six STAR stories
- Record and review yourself regularly
